Knowledge Compilation in a nutshell

Given a Boolean function f:{0,1}X→{0,1}f : \{0,1\}^X \rightarrow \{0,1\}, we want to represent it with a “good” data structure:

  • Succinct.
  • Tractable queries:
    • (weighted) model counting
    • enumeration of models
    • sampling…
  • Tractable transformations:
    • negation
    • conditioning
    • conjunction…

👈 The more of these we have,

the “better” the representation is.

OBDDs

Ordered Binary Decision Diagrams (OBDD) represent Boolean functions as successive ordered tests on variables x1,…,xnx_1,\dots,x_n:

\,

\,

A succinct representation of the Boolean function EVEN(x1,…,x4)EVEN(x_1,\dots,x_4).

  • Linear time algorithm to find a model, count models…

\,

\,

  • Good properties: polynomial time minimization, canonicity, tractable conjoin, negation etc.

Beyond the O in OBDDs

The following syntactically restricted Boolean (AND, OR, NOT) circuits are more general than OBDDs but at a cost:

  • DNNF circuits
    • D = decomposable: AND gates have disjoint variables at each side.
    • NNF = negation normal form: NOT’s appear only at the bottom.
  • Deterministic DNNF circuits
    • determinstic: OR gates receive disjoint models at each side.
  • Structured Deterministic DNNF circuits
    • Structured: the circuit has an underlying tree structure (vtree).
  • SDD (Sentential Decision Diagrams)
    • Like OBDD, but instead of testing just one variable, nodes test more than one variable.

Tree Decision Diagrams (TDD)

Name Counting Negation Conjunction Conditioning Canonicity
TDD ✅ ✅ ✅ ✅ ✅

Tree Decision Diagrams is a new data structure for representing Boolean functions:

  • Special form of structured d-DNNF (variables follow a vtree),
  • Tractable NEGATION, CONJUNCTION, CONDITIONING.
  • CANONICAL form:
    • Minimal
    • Can be computed from any TDD.
    • Natural theoretical description.

OBDD<TDD<SDD\text{OBDD} \ <\ \text{TDD} \ <\ \text{SDD}

TDDs improves the tractability of OBDDs without sacrificing much.

(Bottom-up) determinism

Bottom-up determinism: Each pair of sibling nodes can be the input of at most one node.

Same node can be used twice, as long as it is used with another sibling.

For each assignment of variables and every bag tt, at most one node in bag tt is satisfied.

Negation

For each vtree node tt, add just one tt-node that will take all missing pairs; bottom up!

Bottom up: also add missing pairs with red nodes below!

Red nodes accept the rejected assignments at each level.

Green node computes the negation (new output).

Complexity: O(#vars⋅w2)O(\#vars \cdot w^2) where ww is the width, ie, maximum number of nodes in a bag.

Canonicity and Minimization

Twins contraction

Two nodes N1,N2N_1,N_2 are twins if they have the same siblings for every parent node.

Same sibling for this parent.

But not for this one: these two nodes are not twins.

Same sibling for this parent.

And for this one. They are twins!

We can merge them 👍. This does not change the computed function.

Minimization

Theorem.

Iteratively merging twins until no twins remain converges to a

canonical and minimal TDD computing the same function.

In particular: TDDs can be minimized in polynomial time.

Subfunctions

Let f:2X→{0,1}f : 2^X \rightarrow \{0,1\} and Y⊆XY \subseteq X.

Subfunctions of ff on YY: Boolean functions obtained by fixing variables in X\YX \setminus Y.

Subfunctions and canonicity

Lower bound:

If τ1,τ2\tau_1, \tau_2 are models of the same node NN,

then τ1\tau_1 and τ2\tau_2 define the same subfunction!

At least #𝗌𝗎𝖻𝖿𝗎𝗇𝖼𝗍𝗂𝗈𝗇𝗌(f,Xt)\#\mathsf{subfunctions}(f,X_t) nodes in bag tt for each tt

Upper bound:

If one bag tt has size >#𝗌𝗎𝖻𝖿𝗎𝗇𝖼𝗍𝗂𝗈𝗇𝗌(f,Xt)> \#\mathsf{subfunctions}(f,X_t),

the TDD must contain one pair of twins.

Iteratively contracting twins converges to a canonical minimal TDD!

Bottom-up compilation

def cnf2tdd(F: cnf, T: vtree):
    D = TDD(1, T)
    for c in F:
        Dc = TDD(c, T)
        D.conjoin(Dc)
        D.minimize()
    return D

For a CNF F=C1∧…∧CmF = C_1 \wedge \dots \wedge C_m with nn variables:

  • Let Wi=W_i = width of the TDD obtained after conjoining CiC_i.
  • Runs in time O(nm⋅(max⁡Wi))O(nm \cdot (\max W_i))
  • O(2k⋅nm)O(2^k \cdot nm) for CNF of incidence tw kk (for a well chosen vtree TT).
  • Complexity follows by just analysing the number of subfunctions!
